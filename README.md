# 우리집 안심 중개

부산 지역 인테리어 시공사(파트너)와 고객(집주인)을 매칭해주는 B2B2C 중개 플랫폼 프로토타입입니다.

고객 견적신청 → 매칭 → 파트너 입찰 → 계약 흐름을 중심으로, 파트너 콘솔(포트폴리오/입찰 관리)과
관리자 콘솔(KPI/배정/블랙리스트/스트라이크 관리)까지 포함합니다.

## 현재 상태

순수 프론트엔드 프로토타입입니다. 백엔드/DB 없이 `window.AppState` 전역 JS 객체로만 상태를
관리하며, 새로고침하면 모든 데이터(주문, 입찰 등)가 초기값으로 리셋됩니다.

## 실행 방법

별도 빌드 과정이나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 파일 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 전체 마크업 (홈/견적신청/파트너탐색/마이페이지/파트너센터/관리자패널) |
| `config_state.js` | 초기 설정값, 전역 상태(`window.AppState`), 가상 API(`APIService`) |
| `client_panel.js` | 고객 견적신청, 매칭, 입찰 확인, 계약, 마이페이지 |
| `partner_panel.js` | 파트너/관리자 로그인, 파트너 콘솔, 관리자 콘솔(KPI/배정/모니터링) |
| `cms.js` | 포트폴리오 에디터, 리뷰, 라이트박스, 좋아요 |
| `utils_ui.js` | 공용 유틸(마스킹, 로그, 토스트 등) |
| `premium_theme.css` | 디자인 토큰 (브랜드 블루, 라운드 카드 등) |

## 알려진 이슈

- 파트너/고객 계정 비밀번호가 클라이언트 JS에 평문으로 하드코딩되어 있어 프로덕션에는
  적합하지 않습니다 (`config_state.js`).
- 로그인 검증이 전부 클라이언트 측에서만 이루어집니다.
- 데이터가 영속화되지 않아 새로고침 시 초기화됩니다.
